# VantageNet UiPath collaboration

Windows UiPath Process, VisualBasic expressions, net10.0, hybrid Main.xaml/coded workflows. See project.json for exact package versions. Requires compatible installed UiPath CLI/Robot and cached or restorable activities. Do not reinstall the CLI automatically. Full PowerPoint rendering needs installed PowerPoint; generation uses PowerPoint Activities OpenXML.

Verified environment: Windows, UiPath CLI 1.205.0 with Studio/Robot 26.10 tooling, Python 3.13, Node 25 and PowerPoint 16.0.20527.20196. These are verified versions, not a claim that every earlier release works. Open this hybrid project in compatible Studio Desktop; Studio Web compatibility is not claimed. Python tests need Python 3.10+ and the pinned test dependencies. For an isolated setup from repository root, without global package installation:

```powershell

& ./.venv/Scripts/python.exe -m pip install -r automation/uipath/VantageNet.Reporting/Tests/requirements-test.txt
# Use .venv/Scripts/python.exe in place of python below; Node and UiPath remain external prerequisites.
```

Do not rerun venv creation over an existing environment. Offline tests use only Python standard-library HTTP fixtures; they do not need backend dependencies. No local DLL/cache/database is a source dependency: .local metadata and NuGet paths are regenerated by compatible UiPath tooling from project.json. Package restore may need feed/network access; no global SDK or package installation is performed automatically by these tests.

Implemented: intake/AI-required preview, attended mapping review/controlled import, attended narrative review/template PPTX, and offline synthetic bundle adapter. Prior local human walkthroughs succeeded; no personal decisions or local evidence are included in this checkout. Live AI/RCA, real bundle admission and Action Center remain unverified/blocked. Notifications remain draft-only.

From repository root, resolve your installed CLI and project dynamically:

```powershell
$Uip = (Get-Command uip -ErrorAction Stop).Source
$p = (Resolve-Path automation/uipath/VantageNet.Reporting).Path
$env:UIPATH_CLI_DISABLE_AUTOINSTALL='true'
$env:UIPATH_CLI_DISABLE_VERSION_SYNC='true'
& $Uip rpa validate --project-dir $p --profile vantagenet-local-noauth --output json
& $Uip rpa build $p --profile vantagenet-local-noauth --governance-file-type Default --output json
& $Uip rpa run --file-path AdaptReportBundle.cs --project-dir $p --profile vantagenet-local-noauth --skip-build --input-arguments "bundlePath=$p\Data\s43-report-bundle.synthetic.json" --output json
& $Uip rpa run --file-path ReviewNarrative.cs --project-dir $p --profile vantagenet-local-noauth --skip-build --input-arguments "snapshotPath=$p\Data\s42-report.synthetic.json" --input-arguments "templatePath=$p\Data\provisional-report-template.pptx" --output json
node "$p/Tests/test_narrative_form.mjs" "$p/Output/NarrativeReview/s42-ed-attended-001/narrative-review.html"
```
